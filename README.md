# نظام أليف لإدارة العيادة البيطرية

نواة تطبيق ويب عربية RTL لعيادة بيطرية واحدة، مخصصة للقطط والكلاب، وتعمل داخل شبكة العيادة بدون إنترنت وقت التشغيل.

## المتطلبات

- Windows 10 أو أحدث
- Node.js 24 أو أحدث (يستخدم النظام `node:sqlite` المدمج، لذلك لا يحتاج PostgreSQL أو Docker في هذه النسخة)

## التشغيل

```bash
npm install
npm run dev
```

- افتح `http://localhost:5173` من جهاز الخادم.
- من الأجهزة على الشبكة افتح `http://IP-جهاز-الخادم:5173`.
- الـAPI يعمل على المنفذ `4000` والواجهة على `5173`.
- البيانات تُحفظ في `data/vet-clinic.sqlite` ويتم إنشاء المجلد تلقائيًا.

بعد تنفيذ `npm run build` يمكن تشغيل نسخة الإنتاج ببرنامج واحد:

```bash
npm start
```

وسيخدم الخادم الـAPI والواجهة المبنية معًا على `http://localhost:4000`.

## الحسابات التجريبية

| الدور | المستخدم | كلمة المرور |
| --- | --- | --- |
| مالك النظام | `admin` | `admin123` |
| طبيب | `doctor` | `doctor123` |
| استقبال | `reception` | `reception123` |

> غيّر كلمات المرور قبل التشغيل الحقيقي. تُخزّن كلمات المرور باستخدام `scrypt` مع Salt مستقل لكل مستخدم؛ الحسابات المذكورة مخصصة للنسخة التجريبية فقط.

## ما تم تنفيذه

- تسجيل الدخول والجلسات والصلاحيات الأساسية وسجل التدقيق.
- Dashboard مرتبطة بقاعدة البيانات: المواعيد، الانتظار، الزيارات، العملاء، الحيوانات، الإيرادات والمخزون.
- استقبال ومواعيد: تغيير الحالة وحجز موعد جديد.
- دليل العملاء والحيوانات: بحث، إضافة عميل، إضافة قطة/كلب، رقم Microchip، الوزن، الحساسية والتعقيم.
- زيارات طبية: SOAP، العلامات الحيوية، التشخيص، الخطة العلاجية، المتابعة والوصفة.
- تطعيمات: الجرعة وLot والصلاحية والاستحقاق القادم وقائمة التنبيهات.
- فواتير ومدفوعات: خصم وضريبة ودفع جزئي وتحصيل لاحق وأرصدة العملاء وطباعة A4.
- مخزون: إنشاء أصناف، أرصدة افتتاحية، تسويات، حد إعادة الطلب، خصم آلي مع الفاتورة، ومنع الرصيد السالب.
- واجهة RTL متجاوبة للكمبيوتر والموبايل.
- نسخ احتياطي يدوي محمي بصلاحية المالك/المدير عبر `GET /api/system/backup`.

## ملاحظات التشغيل داخل الشبكة

- يجب السماح للمنفذين `5173` و`4000` في Windows Firewall داخل شبكة Private فقط.
- الإرسال عبر WhatsApp يحتاج اتصالًا بالإنترنت، بينما تظل البيانات والعمليات الأساسية محلية.
- الواجهة لا تطلب خطوطًا أو ملفات من الإنترنت؛ كل أصول التشغيل الأساسية محلية.
