# NOVA BOT ⚡ — بوت واتساب غير رسمي متكامل

بوت واتساب مصري ذكي مبني على **@rexxhayanasi/elaina-baileys** + **API engez.a7a.online** — ألعاب، ذكاء اصطناعي بذاكرة، صوت، تحميل، إدارة وحماية جروبات قوية.

## 🧠 العقل (الرد الذكي)
- **في الخاص**: أي رسالة عادية → نوفا يرد فورًا
- **في الجروب**: منشن له `@البوت` أو رد على رسالة منه أو كلمة سحرية ("نوفا" / "استرو") → يرد
- **شخصية مصرية عامية عندها مشاعر** — بيحس بالمود (زعلان/مبسوط/تعبان/قلقان) ويرد على أساسه
- **يفكر قبل ما يتكلم**: تحليل سريع للرسايل المهمة (الإحساس + القصد + الموضوع) قبل ما يكتب الرد
- **ذاكرة أبديّة بالـ LID**: كل شخص له بروفايل واحد مهما كان جهازه — اسمه ومعلوماته ومشاعره آخر مرة
- **💡 ذكريات طويلة المدى**: بيستخرج ويحفظ أهم مواقف الناس (مقابلة شغل، سفر، زعل...) — ولما ترجع بعد غياب بيستقبلك بالذكرى وبيكمل من ما وقفنا: *"فاكرك كنت متعب — عمد إيه دلوقتي؟"*
- **مقياس الحنية**: لو قلت "بطل الحنية" يبرد لفترة ويرجع تدريجيًا — عمره ما هيقول "أنا مجرد بوت"
- **الأصوات**: `.say نص` • `.animevoice غوكو نص` • أو اكتب "اتكلم" في الشات
- **بعد كل رد زر**: 🎧 قولها بصوت

## 📁 البنية
```
core/   ← api.js (عميل الـ API) • ai.js (المخ) • memory.js (الذاكرة) • persona.js (الشخصية)
          autoreply.js (الرد الذكي) • protection.js (الحماية) • tts.js (الصوت) • send.js (الأزرار والوسائط)
commands/<قسم>/<أمر>.js ← كل أمر ملف لوحده، بيحمل تلقائي
session/ data/ ← الجلسة وقاعدة البيانات (ماتشاركهمش)
```

## 🚀 التشغيل (احترافي — PM2)
```bash
pm2 start ecosystem.config.cjs   # تشغيل دائم — إعادة تشغيل تلقائي لو حصل كراش
pm2 logs nova-bot                # متابعة اللوج
pm2 restart nova-bot             # إعادة تشغيل (بعد إضافة أمر جديد)
pm2 status                       # حالة البوت
```
لو الجلسة موجودة بيتصل لوحده، وإلا صفحة الـ QR: http://localhost:3000 (أو حط رقمك في `pairingPhone`)
