# خطة إعادة بناء أليف كنظام احترافي

## الهدف
تحويل أليف من تطبيق عيادة محلية إلى منصة تشغيل بيطرية موثوقة، سريعة، قابلة للتوسع، وتعمل بأسلوب offline-first داخل العيادة مع إمكانية المزامنة السحابية لاحقًا.

## المقارنة المرجعية
تمت مراجعة اتجاهات أنظمة ezyVet وCovetrus Pulse وDigitail وShepherd وProvet Cloud. نقاط القوة المتكررة فيها: سجل طبي موحد، flowboard لحظي، أتمتة SOAP وتعليمات الخروج، تكامل المعمل والأشعة، إدارة المخزون والفوترة، بوابة عميل، تقارير تشغيلية، ودعم الفروع.

## مبادئ المنتج
1. **سرعة مسار العمل:** أي إجراء يومي شائع يتم خلال ثلاث خطوات أو أقل.
2. **سلامة البيانات:** معاملات ذرية، سجل تدقيق غير قابل للتلاعب، نسخ احتياطي واستعادة مجرّبان.
3. **الأمان افتراضيًا:** أقل صلاحية، جلسات قصيرة مع تدوير refresh token، وعدم إظهار Swagger في الإنتاج.
4. **تجربة عربية أصلية:** RTL كامل، مصطلحات مصرية واضحة، طباعة وفواتير عربية، ودعم الهاتف والكمبيوتر.
5. **قابلية القياس:** فصل الوحدات، واجهات موثقة، مراقبة، واختبارات قبل الدمج.

## خارطة الطريق

### P0 — الثبات والأمان
- توحيد الخادم على NestJS/Prisma وإزالة خادم Express القديم بعد ترحيل أي endpoint مفقود.
- تدوير refresh tokens وربط كل جلسة بجهاز مع إبطال انتقائي.
- صلاحيات دقيقة لكل endpoint ولكل فرع.
- idempotency للفواتير والمدفوعات وحركات المخزون.
- نسخ احتياطي يومي مشفر واختبار استعادة دوري.
- اختبارات وحدة وتكامل وE2E لأهم مسارات العيادة.

### P1 — قلب التشغيل السريري
- flowboard للاستقبال والكشف والتنويم والجراحة.
- قوالب SOAP وبروتوكولات علاج وتطعيم حسب النوع والعمر.
- أوامر معمل وأشعة ونتائج ومرفقات داخل الملف الطبي.
- وصفات مع التحقق من الحساسية والجرعة والوزن والتعارضات.
- discharge instructions وخطة متابعة وتنبيهات تلقائية.

### P2 — التشغيل التجاري
- مشتريات وموردون ودفعات تشغيلية وباركود وتتبع lot/expiry.
- تسويات ومردودات وcredit notes وإغلاق وردية الخزنة.
- تقارير الربحية، متوسط الفاتورة، no-show، دوران المخزون، وأداء الخدمات.
- تعدد الفروع والمخازن وقوائم الأسعار والضرائب.

### P3 — تجربة العميل والذكاء
- بوابة للمالك: المواعيد، الملف، التطعيمات، الفواتير، الدفع والرسائل.
- تذكيرات WhatsApp/SMS مع قوالب وموافقة العميل وسجل إرسال.
- مساعد كتابة SOAP وتلخيص الزيارات مع إبقاء اعتماد الطبيب إلزاميًا.
- بحث موحد سريع ولوحات تنبيه حسب الدور.

## شروط الجاهزية للإنتاج
- نجاح build وtypecheck والاختبارات في CI.
- لا توجد ثغرات عالية أو حرجة، ولا أسرار داخل المستودع.
- تجربة استعادة نسخة احتياطية موثقة وناجحة.
- p95 للعمليات اليومية أقل من 500ms داخل الشبكة المحلية.
- إمكانية تتبع كل تعديل مالي أو طبي إلى مستخدم وتوقيت وقيمة سابقة ولاحقة.
